# Project Name

A bio-inspired autonomous four-wheel rover that uses a camera to detect and follow fish movement.
**Team:** AquaNav
**Program:** Builder-in-Residence

## The problem

Our first idea was to build an automatic medicine dispensing system, but that idea was later dropped. We then thought of making a rover-to-drone. While exploring more ideas, we came across a reel showing a mobile vehicle following fish movement. We found the idea interesting and decided to build our own version.
The idea
AquaNav is a four-wheel mobile rover that uses a Raspberry Pi camera to detect and track a fish or test object. Based on the object's movement, the rover can move forward, reverse, turn left, turn right, or perform a U-turn.
